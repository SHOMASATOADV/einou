入力した全データはスマホ・PC内の大容量 IndexedDB（＋localStorage）に即座に保存されます。数年分の履歴や細かい地図ポリゴンでも容量不足になりません。

☀️ 直射日光下の「屋外高視認」＆片手操作バー

画面右上の「☀️ 屋外高視認」を押すと、まぶしい屋外でも見やすい白黒ハイコントラスト＆大きめ文字に切り替わります。スマホ時は画面下に片手操作バー（入力・マップ・音声・一括登録）が固定表示されます。

🎤 1. 音声入力と毎日の作業日報・営農日誌のつけ方【タブ1】

🎤 おすすめ！話すだけで一括入力（音声コマンド＆音声メモ）
  • 画面上部やSTEP 0の「🎤 音声入力」を押し、マイクに向かって「本場1号から3号まで草刈り2時間半 乗用モア メモ 畦畔良好」のように話すだけで、対象圃場・作業分類・時間・袋数・機械・メモが自動でセットされます。
  • STEP 4の日誌メモ欄では「🎤 音声でメモ」ボタンから、生育観察や引き継ぎ事項をそのまま音声で書き起こせます。
  • 音声非対応ブラウザや圏外時は、モーダル内のテキスト欄に文章を打ち込んでも同じように自動解析できます。
  1. 日付と作業者を確認：左上の日付（「📅 今日」）を確認。よく使う作業は「⚡ ワンタップ履歴呼び出し」で前回設定を一発再現できます。
  2. 対象圃場を選択（複数OK）：タイルをタップ、または「団地一括」「📍 実GPS周辺」「🗺️ 航空写真マップ」「📷 写真GPS判別」で選びます。複数筆でも面積比で自動按分されます。
  3. 作業分類・数量・天候を入力：
    • 🧪 施肥：総袋数を入れるだけで10aあたり N-P-K 成分量を自動計算
    • 🛡️ 防除：2剤混用対応。有効成分別の使用回数上限・収穫前日数(PHI)と風速を自動チェック
    • 🌾 収穫：袋数・屑米(kg)・水分・等級を入力（食味計・伝票は「📸 写真からOCR自動入力」対応）
  4. 「✅ 一括登録」を押す：タイムライン追加・在庫引落・機械アワー加算が同時に完了します。間違いはタイムラインの「✏️ 編集」「🗑️ 取消」で自動ロールバックできます。

🗺️ 2. 航空写真マップでの囲み自動測量 ＆ 📷 ドローン・スマホ写真GPS判別

✏️ 地図上で田んぼを囲んで面積を自動測量
  1. 【タブ1】STEP 1の「🗺️ 航空写真マップで選択」を開きます。
  2. 「✏️ 地図上で田んぼを囲んで新規追加」を押し、田んぼの四隅（3点以上）をクリックします。
  3. 面積（約 ○○ a / ○○○ ㎡）が自動計算され、そのまま圃場名を入れて登録完了です。
📷 ドローン・スマホ写真から圃場を自動判別
  1. 【タブ1】の「📷 写真GPS判別」（または【タブ2】の「📷 写真GPS取込」）を開きます。
  2. 現地で撮った写真（JPEG）を選ぶと、端末内で位置情報(EXIF)を解析し該当する田んぼを自動特定します。
  3. 判別結果を作業対象へ一括セットしたり、GISマップ上に撮影ピンを表示・未登録圃場を新規作成できます。

🌦️ 3. 気象API自動連携・AI予察アラート ＆ GIS進捗カルテ【ヘッダー・タブ2】

  • リアルタイム気象＆ドローン防除可否バー：画面上部の気象バーに現在の天気・気温・湿度・風速を表示。風速 4.0m/s 以上で「🚫 ドローン防除NG」を自動判定し、「▼ 7日間予報・AI予察を見る」で週間予報と詳細アラートを確認できます。
  • 高温登熟・病害虫AI予察：Open-Meteo気象APIと自動連携し、出穂後20日間の白未熟粒・胴割れ警報（27℃超／35℃猛暑日）や、連続降雨・多湿からのいもち病・斑点米カメムシ予察をヘッダーと【タブ2】圃場カルテへ自動通知します。
  • 積算温度（1,000℃刈取予測）＆見回りアラート：【タブ2】カルテで出穂日を設定すると刈取適期予測日を自動計算。獣害・水漏れ等の見回りメモをピン留めするとマップ上に赤い ⚠️ バッジが表示されます。

🚜 4. 機械点検・資材在庫（液剤mL/粒剤kg）＆ 食味計OCR【タブ1・タブ3】

  • 農機具の稼働管理＆点検リセット：【タブ3】から機材を追加可能。日誌登録でアワーが自動加算され、オイル交換時期が近づくと警告します。整備後は「🔧 点検済」でリセットできます。
  • 肥料・農薬在庫の自動引落＆補充：農薬は液剤(mL)／粒剤(kg)の両方に対応し、残量をリアルタイム計算。購入時は「＋入庫補充」ボタンで簡単に在庫を増やせます。
  • 📸 食味計・検査伝票OCR：収穫入力画面の「📸 食味計・伝票を写真読取」から撮影すると、食味値・水分・タンパク・整粒歩合・等級を自動抽出してフォームへ反映できます（Gemini APIキーは【タブ5】で設定可能）。

📈 5. JA提出用A4帳票・10a採算試算 ＆ AI最適施肥（二次回帰分析）【タブ4】

  • 📄 ① JA提出「生産履歴記帳簿」／ 📋 ② 作業日報：品種・団地で絞り込み、「🖨️ A4フォーマットで一発印刷 / PDF保存」や「📥 Excel/CSV出力」で提出書類を即作成できます。
  • 📊 ③ 圃場別「10a採算・粗利ランク（S〜C）」試算：肥料・農薬・労務・機械費と反収・屑米売上から10a粗利を自動計算。想定米価や時給を変えて即座にシミュレーションできます。
  • 📈 ④ AI施肥分析（チッソ×反収 二次曲線回帰）：最小二乗法（y = ax² + bx + c）で最も反収が高くなる最適チッソ施肥量（ピーク値）を自動算出し、過剰施肥・施肥不足の田んぼをグラフと表で診断します（サンプル7筆デモ試算対応）。

☁️ 6. Googleスプレッドシート双方向同期・他社移行・バックアップ【タブ5】

  • ☁️ GAS双方向同期（送信 ＆ 最新マスタ取得）：URLと同期用トークンを設定すれば、「今すぐ同期送信 (doPost)」で未送信日誌を重複なく自動按分・帳票反映でき、「最新マスタを取得 (doGet)」でスプレッドシート側の最新マスタをスマホへ取り込めます。
  • 🔄 他社ソフト・筆ポリゴン移行：アグリノート・クボタKSAS・eMAFF筆ポリゴン（GeoJSON）の面積単位（㎡/ha→a）とポリゴン形状を自動変換して取り込めます。
