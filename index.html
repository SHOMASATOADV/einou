💡 基本の仕組み（電波圏外でも消えない自動保存）

入力した作業日誌・田んぼ・農機具・資材在庫のデータは、すべてお使いのスマホ・パソコン内（ブラウザの localStorage）に自動で即座に保存されます。山間部の電波圏外で入力しても消えません。詳細な説明書ファイルは docs/user_manual.md にも収録されています。

📱 1. 毎日の作業日報・営農日誌（天候・メモ）のつけ方【タブ1】

  1. 日付と作業者を確認：左上の日付（「📅 今日」ボタンで本日にセット）と作業者名を確認します。「⚡ ワンタップ履歴呼び出し」で前回と同じ設定を1タップで呼び出すこともできます。
  2. 作業した田んぼ（複数可）を選択：田んぼタイルをタップ（または「⛰️ 上山田団地を一括選択」「📍 実GPS現在地周辺を選択」「🗺️ Googleマップで選択」）して選びます。複数選んだ場合も面積比で自動按分されます。
  3. 作業分類を選択：
    • 🌱 施肥：肥料と総袋数を入力 → 10aあたりチッソ(N)・リン酸(P)・カリ(K)成分量を自動計算
    • 🚁 防除：第1・第2農薬（混用可）を選択 → 有効成分ごとの使用回数上限・収穫前日数(PHI)を自動チェック
    • 🌿 草刈り / 🚜 耕起 / 🌾 収穫：収穫は総重量入力で10aあたり反収（kg・俵）を自動算出
    • 📔 観察・日誌のみ：資材を使わない日々の見回りや生育ステージ観察のみを記録
  4. 天候・気温・観察メモを入力：天候（☀️晴・⛅曇・🌧️雨など）や気温、自由メモ・引き継ぎ事項を入力します（クイックタグで1タップ追記可能）。
  5. 「✅ この内容で一括登録」を押す：右側のタイムラインに即座に追加され、在庫の引き落としや機械アワーの加算も自動で行われます。間違えた場合はタイムラインの「✏️ 編集」や「🗑️ 取消」からいつでも直せます。

🗺️ 2. Googleマップ（航空写真）での圃場選択・田んぼを囲んで新規作図＆面積自動測量

🅰️ 登録済みの田んぼを航空写真で選ぶ
  1. 【タブ1】STEP 1の「🗺️ Googleマップで選択」を押します。
  2. 航空写真上の田んぼの枠（ポリゴン）またはピンをタップすると選択（緑色✓）／解除が切り替わります。
  3. 「🚗 選択圃場をGoogleマップ経路案内」で現地までのナビも開けます。
🅱️ 地図上で田んぼを囲んで面積を自動測量＆新規登録
  1. マップ右上の「✏️ 地図上で田んぼを囲んで新規追加」を押します。
  2. 航空写真上で田んぼの四隅（3点以上）を順番にクリックします。
  3. 赤い枠で囲まれ、面積（約 ○○ a / ○○○ ㎡）が自動測量されます。
  4. 「✅ この範囲で圃場を登録」を押し、圃場名を入れて保存すれば完了です！

🌡️ 3. GIS進捗マップ・出穂後積算温度（1,000℃刈取予測）・見回りアラート【タブ2】

  • 作業別の色分け進捗確認：基肥・防除・草刈り・収穫の進捗状況を「📐 進捗ボード」または「🛰️ Googleマップ(航空写真)」上で色分け表示します。
  • 水稲「出穂後積算温度（1,000℃）」予測：右側の圃場カルテで「🌾 出穂日」と「🌡️ 日平均気温」を入力すると、積算温度の進捗率と刈取適期予測日（あと何日か）を自動計算します。
  • 現地見回り＆被害アラート：カルテ下部の「⚠️ 被害・見回りメモ」から獣害・水漏れ・雑草などのアラートをピン留めすると、マップ上に赤い ⚠️ バッジが表示されます。

🚜 4. 機械（農機具）・肥料・農薬の新規追加と在庫・点検管理【タブ3・タブ5】

  • 農機具の追加・点検リセット：【タブ3】の「＋ 新規機材を追加」からトラクター・コンバイン・ドローン等を登録できます。日誌入力で稼働時間が自動加算され、オイル交換時期になると警告が出ます。「🔧 オイル交換・点検済として記録」でリセットできます。
  • 肥料・農薬の追加・入庫補充：【タブ3】の「＋ 肥料を追加」「＋ 農薬を追加」から新しい銘柄を登録できます。追加購入した際は各カードの「＋10袋 入庫補充」等で在庫を増やせます。

🖨️ 5. JA提出用A4帳票・10aあたり採算ランク試算・バックアップ復元【タブ4・タブ5】

  • JA提出「生産履歴記帳簿」＆A4印刷：【タブ4】で品種や団地を絞り込み、「🖨️ A4横サイズで印刷 / PDF保存」または「📥 帳票CSV出力」でそのままJAへ提出できる帳票を出力できます。
  • 圃場別「10aあたり原価・粗利・採算ランク（S〜C）」試算：【タブ4】の「💴 圃場別10a採算・粗利試算表」で、各田んぼの肥料費・農薬費・労務費・機械費と反収から粗利益を自動試算します（想定米価・時給シミュレーション対応）。
  • 他社データ移行・GAS連携・JSONバックアップ：【タブ5】からアグリノート・KSAS・eMAFF筆ポリゴンの取り込み、Googleスプレッドシート（GAS）への一括送信、「📥 JSONバックアップ保存」「📤 JSONバックアップから復元」が行えます。
