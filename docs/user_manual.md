# 📖 らくらく営農日誌 Next — 取扱説明書・使い方ガイド

本ガイドは、**「らくらく営農日誌 Next」** を初めて使う方でも迷わず操作できるようにまとめた取扱説明書です。  
アプリ画面右上の **「📖 使い方・説明書」** ボタンからも、いつでも簡易版を確認できます。

---

## 🔰 はじめての方へ：3ステップでわかる使い方の流れ

最初は難しそうに見えますが、基本の流れは **「① 準備 → ② 毎日入力 → ③ 確認・提出」** の3つだけです。

```text
┌──────────────────────────────────────────────────────────┐
│ ① 最初の準備（最初だけ）                                   │
│   自分の田んぼ・農機具・肥料・農薬を登録する（タブ5 / タブ3）  │
└───────────────────────────┬──────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────┐
│ ② 毎日の作業記録（毎日）                                   │
│   田んぼを選んで作業を入力 →「一括登録」（タブ1）            │
│   ※ 複数の田んぼを選んでも、面積に応じて自動で割り振られます！ │
└───────────────────────────┬──────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────┐
│ ③ 進捗の確認・JAへの提出（必要なとき）                      │
│   ・進み具合や刈取予測・見回りメモを見る（タブ2）            │
│   ・JA提出用の「生産履歴記帳簿」をA4印刷する（タブ4）        │
└──────────────────────────────────────────────────────────┘
```

## 📖 よく使う用語・単位のミニ辞典

アプリ内で出てくる専門用語の意味をまとめました。

- **圃場（ほじょう）**：田んぼ・畑の区画のことです。
- **a（アール） / 10a（じゅうアール）**：面積の単位です。**10a ＝ 1反（約300坪 ＝ 1,000㎡）** です。
- **面積按分（めんせきあんぶん）**：複数の田んぼにまとめて肥料や農薬をまいたとき、それぞれの田んぼの広さ（面積比）に応じて使用量を自動で割り振ることです。
- **PHI（収穫前日数）**：農薬をまいてから「最低でも何日あければ収穫してよいか」の安全基準です。基準に引っかかる場合は赤い警告が出ます。
- **アワーメーター**：トラクターなどの農機具が「累計何時間動いたか」を示す時間計です。作業を登録すると自動で加算されます。
- **JSON（ジェイソン）バックアップ**：アプリ内の全データ（田んぼ・機械・在庫・日誌）を1つのファイルにまとめて保存する形式です。

## 1. アプリの開き方とデータの保存ルール

### 💻 パソコン・スマホでの開き方
- フォルダ内の **`index.html`** をダブルクリックすると、普段お使いのブラウザ（Google Chrome / Edge / Safari など）ですぐに開きます。
- インターネットが繋がる場所では **Googleマップの航空写真** が表示され、山間部などの電波圏外では自動的に **オフライン用マップ** に切り替わります。

### 💾 データが消えない仕組みと注意点
- 入力した日誌や登録したデータは、すべてお使いのスマホ・パソコンのブラウザ内（`localStorage`）に**即座に自動保存**されます。
- 電波が届かない山間部の田んぼで入力しても、ブラウザを閉じてもデータは消えません。

> ⚠️ **大切なお知らせ（データ消失を防ぐために）**  
> 「ブラウザの閲覧履歴・サイトデータの全削除」を行うと、保存されているデータも消えてしまいます。  
> 機種変更や万が一に備えて、月に1回や作業の区切りに **[タブ5] ＞「📥 JSONバックアップ保存」** でパソコンやスマホにファイルを保存しておくことを強くおすすめします。

## 2. 画面の全体像（5つのタブとマークの見方）

画面上部の5つのボタンで機能を切り替えます。

| タブ番号・名称 | 主な役割 |
| :--- | :--- |
| **📱 1. 現場一括入力** | 毎日の作業日誌の入力、Googleマップでの田んぼ選択・新規作図、過去日誌の検索・修正 |
| **🗺️ 2. GIS進捗・カルテ** | 作業別の色分け進捗マップ、田んぼごとのカルテ、出穂後積算温度（刈取予測）、被害アラート |
| **🚜 3. 機械・資材在庫** | 農機具の追加・アワーメーター点検管理、肥料・農薬の追加・入庫補充・在庫確認 |
| **🖨️ 4. JA・行政 A4帳票** | JA提出用「生産履歴記帳簿」、作業日報一覧、10aあたり採算ランク試算、A4印刷・CSV出力 |
| **🔄 5. 他社データ移行・設定** | 他社ソフトからのデータ取込、マスタ登録、Googleスプレッドシート連携、バックアップ保存・復元 |

### マーク・色の見方
- **`✓`（緑枠）**：現在選択中の田んぼ
- **緑色のカード／マップ**：作業完了
- **青色のカード／マップ**：作業中
- **灰色のカード／マップ**：未着手
- **赤い `⚠️` マーク**：未解決の被害・見回りメモあり（または農薬の使用上限・PHI警告）

## 3. 【最初の準備】自分の田んぼ・機械・肥料・農薬を登録する

アプリを最初に開いたときは、動作を試せるように **サンプルデータ** が入っています。  
まずは練習としていくつか入力してみて、本番運用を始める際に自分のデータへ切り替えましょう。

1. **サンプルデータを消して最初から始める場合**  
   **[🔄 5. 他社データ移行・設定]** タブで「🔄 初期サンプルにリセット」や既存データの削除・編集ができます。
2. **田んぼ（圃場）を増やす方法（3通り）**
   - **方法1（一番かんたん）**：**[📱 1. 現場一括入力]** タブ ＞「🗺️ Googleマップで選択」＞「✏️ 地図上で田んぼを囲んで新規追加」で、航空写真を見ながら囲む（[第5章](#方法b航空写真で田んぼを囲んで面積を自動測量新規登録するおすすめ)）。
   - **方法2（手入力）**：**[🔄 5. 他社データ移行・設定]** タブの圃場登録フォームから名前・面積(a)・品種を入力して追加。
   - **方法3（他社ソフトから移行）**：アグリノート・KSAS・eMAFF筆ポリゴンのファイルを一括取込（[第9章](#-他社営農ソフト行政データの1クリック取り込み)）。
3. **自分の農機具・肥料・農薬を増やす**
   - **[🚜 3. 機械・資材在庫]** タブ（またはタブ5）から「＋ 新規機材を追加」「＋ 肥料を追加」「＋ 農薬を追加」でいつでも追加・削除できます。

## 4. 【毎日の記録】タブ1で作業日誌・営農日誌をつける

**「複数の田んぼで同じ作業をしたとき」でも、1回の入力だけでOKです。**  
入力した合計量や作業時間は、選んだ田んぼの広さ（面積比）に応じて自動で配分されます。

### 📌 具体例でイメージする「面積按分」
> **例：** 「上山田1号（**30a**）」と「上山田2号（**20a**）」の2枚（合計50a）を選び、肥料を「合計 **10袋（200kg）**」と入力して登録した場合
>
> - 上山田1号（30a）には **120kg**（10aあたり40kg）として記録
> - 上山田2号（20a）には **80kg**（10aあたり40kg）として記録  
> ※ 1枚ずつ電卓で計算して入力し直す手間はありません！

---

### 操作手順（上から順番に選んでいくだけ）

#### 手順①：日付と作業者を確認する
- 画面左上の日付（**「📅 今日」** ボタンで今日の日付にセット可能）と作業者名を確認します。
- よく使う作業は **「⚡ ワンタップ履歴呼び出し」**（基肥散布・ドローン防除・畦畔草刈り）を押すと、設定を一発で呼び出せます。

#### 手順②：作業した田んぼを選ぶ（STEP 1）
やりやすい方法で田んぼを選びます（複数選択OK）。
1. **カードをタップして選ぶ**：田んぼのカードをクリックすると緑色（`✓`）になります。
2. **団地ごとまとめて選ぶ**：「⛰️ 上山田団地を一括選択」「🌊 川向団地を一括選択」で一括選択できます。
3. **📍 実GPS現在地周辺を選択**：今いる場所の近くにある田んぼを自動で選びます。
4. **🗺️ Googleマップで選択**：航空写真を見ながら田んぼをタップして選べます（[第5章](#5-地図ナビgoogleマップ航空写真で選ぶ囲む道案内する)）。

#### 手順③：作業分類と使った資材・機械を選ぶ（STEP 2・STEP 3）
6つの分類から該当するものを選びます。

| 作業分類 | 入力する主な内容 | 自動で計算・チェックされること |
| :--- | :--- | :--- |
| **🌱 施肥** | 肥料銘柄、使った総袋数（または総kg） | 各田んぼの10aあたりN・P・K成分量 |
| **🚁 防除（農薬）** | 第1農薬（第2農薬の混用も可）、希釈倍率、総散布量 | **有効成分ごとの使用回数上限・収穫前日数(PHI)** の安全チェック |
| **🌿 草刈り・畦畔** | 作業内容、使用した機械・作業時間 | 機械アワーメーター加算 |
| **🚜 耕起・代かき** | 作業内容、使用した機械・作業時間 | 機械アワーメーター加算 |
| **🌾 収穫・刈取** | 収穫した総重量（kg または 30kg袋数）、品質等級 | 各田んぼの **10aあたり反収（kg・俵）** |
| **📔 観察・日誌のみ** | 資材を使わない見回り・水回り確認など | 営農日誌タイムラインへの記録 |

#### 手順④：天候・気温・観察メモを入力する
- **天候**（☀️晴・⛅曇・🌧️雨など）と **気温(℃)** を選びます。
- **生育観察・作業メモ・引き継ぎ事項** には自由な文章を入力できます。下の「💧 水回り・落水確認」「🐗 畦畔・獣害点検」などのクイックタグを押すと、ワンタップで定型文を入れられます。

#### 手順⑤：「✅ この内容で一括登録」ボタンを押す
- 画面下の緑色の大きなボタンを押すと登録完了です。
- 右側の **「📔 営農日誌・作業タイムライン」** に追加され、以下がすべて自動で更新されます。
  1. 各田んぼの累積成分量（N-P-K）・農薬使用回数・進捗状況
  2. 肥料・農薬の現在庫からの引き落とし
  3. 使用した農機具のアワーメーター（稼働時間）の加算

### 間違えて登録したときの直し方（編集・取消）
> 💡 **あとからいつでも直せます！**  
> 右側のタイムラインにある履歴カードの **「✏️ 編集」** を押すと、入力フォームに内容が戻って修正（上書き保存）できます。  
> **「🗑️ 取消」** を押すと履歴が消え、減った在庫や増えた機械アワーも自動で元に戻ります。

## 5. 【地図・ナビ】Googleマップ（航空写真）で選ぶ・囲む・道案内する

Googleマップの航空写真を使って、見た目で直感的に田んぼを選んだり、新しい田んぼの面積を測って登録できます。

### 方法A：登録済みの田んぼを航空写真でタップして選ぶ
1. **[📱 1. 現場一括入力]** タブの STEP 1 にある **「🗺️ Googleマップで選択」** を押します（または **[🗺️ 2. GIS進捗・カルテ]** タブで **「🛰️ Googleマップ(航空写真)」** に切り替えます）。
2. 航空写真の上に、登録済みの田んぼの枠（ポリゴン）とピンが表示されます。
3. **田んぼの枠またはピンをタップ** すると、選択（緑色 `✓`）／解除が切り替わります。

### 方法B：航空写真で田んぼを囲んで、面積を自動測量＆新規登録する（おすすめ！）
まだ登録していない新しい田んぼを、航空写真を見ながらその場で追加できます。
1. Googleマップ選択パネルの右上にある **「✏️ 地図上で田んぼを囲んで新規追加」** を押します。
2. 航空写真を拡大し、**追加したい田んぼの角（四隅など）を順番に3箇所以上クリック** します。
3. クリックするたびに赤い点線で田んぼが囲まれ、画面上に **面積（約 ○○ a / ○○○ ㎡）がリアルタイムで自動計算** されます。
   - 点を打ち直したいときは **「🗑️ 頂点をクリア」** を押します。
4. 囲み終わったら **「✅ この範囲で圃場を登録」** を押します。
5. 自動で **[🔄 5. 他社データ移行・設定]** の新規圃場登録フォームが開き、**緯度・経度・面積(a)・ポリゴン形状がすべて自動入力された状態** になります。
6. あとは **「圃場名（例：山田3号田）」** や **「品種」** を入れて **「＋ 圃場マスタへ追加保存」** を押せば完了です！

### 方法C：選んだ田んぼまでGoogleマップで道案内（ナビ）する
- 飛び地や新しく借りた田んぼへ行くときは、STEP 1 の **「🚗 選択圃場をGoogleマップ経路案内」** ボタン（または各田んぼカルテの **「🗺️ Googleマップで開く」**）を押すと、Googleマップのルート案内が別タブで開きます。

## 6. 【進捗・見回り】タブ2で全体の進み具合・刈取予測・被害メモを管理する

**[🗺️ 2. GIS進捗・カルテ]** タブでは、地域全体の作業状況や生育・被害を一目で確認できます。

### 🗺️ 作業別の進捗色分けマップ
- 上部のボタン（**🌱 基肥・施肥進捗** ／ **🚁 防除進捗** ／ **🌿 畦畔草刈り** ／ **🌾 収穫・反収**）を切り替えると、各田んぼが **「完了（緑）」「作業中（青）」「未着手（灰）」「要注意（赤）」** で色分け表示されます。
- **「📐 進捗ボード」** と **「🛰️ Googleマップ(航空写真)」** をワンタップで切り替えられます。

### 🌡️ 水稲「出穂後積算温度（1,000℃）」＆刈取適期予測
- 右側の「圃場個別カルテ」で田んぼを選び、**「🌾 出穂日」** と **「🌡️ 日平均気温(℃)」** を入力すると、出穂後からの積算温度と目標1,000℃に対する進捗バー、および **刈取適期予測日（あと何日か）** が自動表示されます。

### 📸 現地見回りメモ＆被害アラート（獣害・水漏れ・雑草）
- 田んぼを見回って異常を見つけたときは、右側のカルテ下部にある **「⚠️ 被害・見回りメモ」** に内容（例：「北側畦畔にイノシシ掘り返し跡あり」）を入力し、区分（🐗獣害・💧水漏れ・🌿雑草・🐛病害虫）を選んで **「＋ アラート追加」** を押します。
- 未解決のアラートがある田んぼには、マップやタイル上に赤い **`⚠️`** マークが表示されます。処置が終わったら **「✓ 解決済」** ボタンで消せます。

## 7. 【機械・在庫】タブ3で農機具の点検・肥料や農薬の在庫を管理する

**[🚜 3. 機械・資材在庫]** タブ（または **[🔄 5. 他社データ移行・設定]** タブ）から、農機具や資材を管理できます。

### 🚜 農機具（機材）の追加・オイル交換点検リセット
1. **新規機材の追加**：**「＋ 新規機材を追加」** ボタンを押し、機材名（例：`クボタ コンバイン ER470`）、分類、現在アワー(h)、点検間隔(hごと)、稼働単価(円/h)を入力して保存します。
2. **自動加算とアラート**：日誌でその機械を使って作業登録すると稼働時間が自動で増え、点検間隔（50時間ごと等）に近づくと **「オイル交換時期超過」** アラートが表示されます。
3. **点検・整備記録**：整備が終わったら **「🔧 オイル交換・点検済として記録」** ボタンを押すとカウントがリセットされます。不要になった機材は **「🗑️ 削除」** で削除できます。

### 🧪 肥料・🛡️ 農薬の新規追加と入庫補充
1. **肥料の追加**：**「＋ 肥料を追加」** ボタンから、肥料名・N/P/K成分(%)・1袋重量(kg)・初期在庫・単価を入力して登録します。
2. **農薬の追加**：**「＋ 農薬を追加」** ボタンから、農薬名・登録番号・**有効成分名**・使用上限回数・収穫前日数(PHI)・初期在庫・単価を入力して登録します。
3. **在庫の入庫補充**：JAや資材店から買い足したときは、各資材カードの **「＋10袋 入庫補充」** などのボタンを押すと在庫数が加算されます。

## 8. 【提出・試算】タブ4でJA提出用の帳票・A4印刷・採算シミュレーションをする

**[🖨️ 4. JA・行政 A4帳票]** タブでは、日々の入力データから提出用書類や経営分析表を自動作成します。

### 📄 3種類の帳票モード切替
1. **JA提出用「生産履歴記帳簿」**
   - 品種（コシヒカリ・つきあかり等）や団地・個別圃場で絞り込めます。
   - **施肥履歴（10aあたりN-P-K成分累計）** と **防除履歴（農薬登録番号・有効成分別の総使用回数・収穫前日数判定・最終散布日からの経過日数）** がJA提出フォーマットで自動集計されます。
2. **作業日報・労務機械稼働一覧**
   - 誰が・いつ・どの田んぼで・どの機械を何時間動かしたか、当日の天候・観察メモを含めた一覧表を出力します。
3. **💴 圃場別「10aあたり原価・粗利・採算性」試算表**
   - 各田んぼに投入した **肥料費＋農薬費＋労務費＋機械稼働費** と、収穫した **反収×米価（売上）** から、**10aあたりの粗利益と採算ランク（S / A / B / C）** を自動算出します。
   - 画面上の「想定米価（円/60kg俵）」や「労務時給（円/h）」を変えると、リアルタイムで全圃場の採算シミュレーションが更新されます。

### 🖨️ A4印刷・PDF保存・CSV出力
- **「🖨️ A4横サイズで印刷 / PDF保存」** ボタンを押すと、画面上のメニューやボタンが自動的に隠れ、A4用紙にきれいに収まるレイアウトで印刷（またはPDF保存）できます。
- Excelで加工したい場合は **「📥 帳票CSV出力」** を押すと、文字化けしないBOM付きCSVファイルがダウンロードされます。

## 9. 【移行・連携・バックアップ】タブ5でデータ移行・スプレッドシート連携・保存をする

**[🔄 5. 他社データ移行・設定]** タブでは、外部データの取り込みやバックアップを行います。

### 🔄 他社営農ソフト・行政データの1クリック取り込み
- **アグリノート (AgriNote)** のほ場台帳CSV（面積 `㎡` を `a` に自動換算）
- **クボタ KSAS** の作業日誌CSV（面積 `ha` を `a` に自動換算）
- **農林水産省 eMAFF農地ナビ / Z-GIS** の筆ポリゴン（GeoJSONファイル）
- サンプル読込ボタンまたはファイル選択で読み込み、プレビュー確認後に **「✅ 変換データをマスタ・履歴へ一括統合」** を押すだけで取り込めます。

### ☁️ Googleスプレッドシート（GAS）連携
- 同梱の `gas/Code.gs` をGoogleスプレッドシートに設定して発行したウェブアプリURLを入力すると、**「☁️ スプレッドシート同期」** ボタン1つでスマホ内の日誌データをGoogleスプレッドシートへ一括送信できます（詳しい構築手順は `docs/pwa_and_gas_setup_guide.md` をご覧ください）。

### 💾 JSONバックアップ保存・1クリック復元・初期リセット
- **「📥 JSONバックアップ保存」**：現在の全データを1つの `.json` ファイルとしてパソコンやスマホに保存します。
- **「📤 JSONバックアップから復元」**：保存しておいた `.json` ファイルを選ぶだけで、すべての田んぼ・在庫・日誌データを1クリックで元通りに復元します。
- **「🔄 初期サンプルにリセット」**：練習でいろいろ入力した後、最初のサンプル状態に戻したいときに使います。

## 10. よくある質問（FAQ）・困ったときは

### Q1. Googleマップの航空写真が表示されず、図形（SVG）のマップになります。
- **A.** パソコンやスマホがインターネットに繋がっているかご確認ください。オフライン（圏外）状態や「📡 圏外テスト切替」がオンになっている場合は、通信を使わないオフライン用マップが表示されます。

### Q2. 新しい田んぼの緯度・経度がわかりません。
- **A.** 緯度・経度を手入力する必要はありません！ **[📱 1. 現場一括入力]** タブの **「🗺️ Googleマップで選択」＞「✏️ 地図上で田んぼを囲んで新規追加」** を使えば、航空写真の上で田んぼの角をクリックするだけで位置・形状・面積(a)がすべて自動入力されます。また、Googleマップの共有URLを貼り付けて座標を自動抽出することもできます。

### Q3. 複数の田んぼにまとめて肥料をまいたとき、1枚ずつの量はどう計算されますか？
- **A.** たとえば 30a と 20a の田んぼ（合計50a）を選んで「合計10袋（200kg）」と入力すると、面積比（3:2）に応じて自動的に **30aの田んぼに120kg、20aの田んぼに80kg（どちらも10aあたり40kg）** として配分・記録されます。

### Q4. ブラウザを閉じてもデータは消えませんか？
- **A.** 消えません。ブラウザの `localStorage` に自動保存されているため、次回開いたときも続きから使えます。ただし「ブラウザの閲覧履歴・キャッシュの全削除」を行うと消える場合があるため、大切なデータは定期的に **[タブ5] ＞「📥 JSONバックアップ保存」** でファイルに保存してください。
