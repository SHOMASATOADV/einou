## 📖 よく使う用語・単位のミニ辞典

- **圃場（ほじょう）**：田んぼ・畑の区画のことです。
- **a（アール） / 10a（じゅうアール）**：面積の単位です。**10a ＝ 1反（約300坪 ＝ 1,000㎡）** です。
- **面積按分（めんせきあんぶん）**：複数の田んぼにまとめて肥料や農薬をまいたとき、それぞれの田んぼの広さ（面積比）に応じて使用量を自動で割り振ることです。
- **PHI（収穫前日数）**：農薬をまいてから「最低でも何日あければ収穫してよいか」の安全基準です。違反時は赤い警告で誤登録をブロックします。
- **EXIF（エグジフ）GPS**：ドローンやスマホで撮影した写真（JPEG）に自動記録されている撮影地点の緯度・経度情報です。
- **IndexedDB（インデックスドDB）**：ブラウザに内蔵された大容量データベースです。数年分の作業日誌や複雑な地図データも5MB制限を気にせず安全に保存できます。

## 1. アプリの開き方・屋外モード・データ保存の仕組み

### 💻 パソコン・スマホでの開き方
- ブラウザ（Google Chrome / Edge / Safari）で開くだけで即座に使えます（PWA対応のため、スマホの「ホーム画面に追加」でアプリのように起動できます）。
- オンライン時は **航空写真マップ・リアルタイム気象API・音声認識** が動作し、山間部の電波圏外では自動的に **オフライン用マップ＆キャッシュ** へ切り替わります。

### ☀️ 屋外ハイコントラストモード ＆ 📱 スマホ片手操作バー
- **☀️ 屋外高視認モード**：画面右上の **「☀️ 屋外高視認」** ボタンを押すと、直射日光下でも白飛びせずハッキリ読める **白背景・純黒文字・太枠（2px）・大きめフォント** に切り替わります（設定は自動記憶されます）。
- **📱 モバイル片手操作バー**：スマホ表示時は画面下部に **「📱 入力」「🗺️ マップ」「🎤 音声入力」「✅ 一括登録」** の4ボタンが固定表示され、トラクター乗車前後でも親指1本で操作できます。

### 💾 電波圏外でも消えない大容量自動保存（IndexedDB）
- 入力した全データは端末内の **`IndexedDB`**（＋ `localStorage` フォールバック）に即座に保存されます。
- 現在のデータ使用量（KB）や登録件数は **[🔄 5. 他社データ移行・設定]** タブのストレージ表示バッジからいつでも確認できます。

> ⚠️ **データ保護のお願い**  
> ブラウザの「サイトデータをすべて削除」を実行すると端末内データも消去されます。機種変更や万が一に備えて、定期的に **[タブ5] ＞「📥 JSONバックアップ保存」** でファイルを保存しておくことをおすすめします。

## 3. 【最初の準備】自分の田んぼ・機械・肥料・農薬を登録する

1. **田んぼ（圃場）を増やす方法（4通り）**
   - **方法1（一番かんたん）**：**[📱 1. 現場一括入力]** ＞「🗺️ 航空写真マップで選択」＞「✏️ 地図上で田んぼを囲んで新規追加」で航空写真を見ながら囲む。
   - **方法2（写真から作成）**：現地で撮った写真を「📷 写真GPS判別」へ読み込ませ、未登録地点からワンタップ作成。
   - **方法3（手入力）**：**[🔄 5. 他社データ移行・設定]** タブの圃場登録フォームから追加。
   - **方法4（他社ソフトから移行）**：アグリノート・KSAS・eMAFF筆ポリゴン（GeoJSON）を一括取込。
2. **農機具・肥料・農薬を増やす**

## 4. 【音声入力と毎日の記録】タブ1で話すだけ・タップだけで日誌をつける

### 🎤 話すだけで一括入力（音声コマンド ＆ 音声メモ）
キーボード入力が面倒な現場では、音声入力を使うと数秒で入力が完了します。

1. **一括音声コマンド（「🎤 音声入力」ボタン）**
   - ヘッダー・STEP 0・スマホ下部バーの **「🎤 音声入力」** を押し、赤いマイクボタンをタップして普段通りに話します。
   - **発話の例**：
     - 「`本場1号から3号まで草刈り2時間半 乗用モア メモ 畦畔良好`」
     - 「`上山田団地 防除 1時間半 ドローン`」
     - 「`昨日 本場1号と2号 施肥 10袋 2時間 トラクター`」
   - 対象圃場（範囲指定・団地一括・名前一致）・作業分類・時間・袋数・日付・機械・天候・メモが自動で解析され、フォームに反映されます。確認後 **「✅ この内容でそのまま作業登録する」** で即登録できます。
   - ※ 音声認識非対応ブラウザや圏外時は、モーダル内のテキスト入力欄に文章を打ち込んでも同じ解析が使えます。
2. **日誌メモ欄の音声書き起こし（「🎤 音声でメモ」ボタン）**
   - STEP 4（営農日誌メモ）の **「🎤 音声でメモ」** を押すと、生育観察や引き継ぎ事項をそのままリアルタイムで文字起こしできます。

### 🧠 AI営農アドバイザー（今週の重点ToDoリスト ＆ 1タップ入力転送）
- タブ1の最上部に、蓄積された **日誌メモ・未解決の見回りアラート（獣害・水漏れ・雑草等）・出穂後積算温度（落水準備／刈取適期）・Open-Meteo 気象AI予察** を自動解析した **「🧠 今週の重点ToDoリスト」** が表示されます。
- 各タスクの **「⚡ 1タップで入力へセット」** を押すと、対象圃場・作業分類・引き継ぎメモがそのまま下の入力フォームへ自動反映され、確認後すぐに登録できます。

### 📷 JANバーコード / QRコード読み取り 自動資材選択
- STEP 3（資材入力）右上の **「📷 JAN/QRスキャン選択」** を押し、スマホカメラで農薬ボトルや肥料袋のJANコード・QRコードをかざすと、該当する肥料／農薬を自動選択し、作業分類（「施肥」／「防除」）も自動で切り替わります（農薬は **「＋ 第2農薬(混用)にセット」** にも対応）。
- **未登録JANコードのその場紐付け**：まだマスタに登録されていないJANを読み取った場合は、画面内のリストから既存資材を選んで **「🔗 この資材にJANを紐付け保存」** を押すだけで、次回からはかざすだけで一発選択できるようになります。
- カメラ自動検出非対応のブラウザでも、**「🖼️ 写真から読取」** または **JAN番号・農薬登録番号（例：`20142`）の手入力** で同じように照合できます。

### 📱 タップ操作での標準入力手順（複数圃場も自動で面積按分）

> **📌 面積按分のイメージ**  
> 「本場1号（**30a**）」と「本場2号（**20a**）」（計50a）を選び、肥料を「合計 **10袋（200kg）**」と入力すると、自動的に **本場1号に120kg・本場2号に80kg（どちらも10aあたり40kg）** として配分・記録されます。

1. **日付・作業者・プリセット確認**：左上の日付（**「📅 今日」**）を確認。**「⚡ ワンタップ履歴呼び出し」** で前回と同じ設定を一発再現できます。
2. **対象圃場を選択（STEP 1）**：カードタップ、団地一括、**「📍 実GPS周辺」**、**「🗺️ 航空写真マップ」**、**「📷 写真GPS判別」** のいずれかで複数選択します。
3. **作業分類・時間・機械・詳細天候を選択（STEP 2）**：
   - 作業分類（耕起・代かき・田植え・草刈り・施肥・防除・収穫）を選びます。
   - 天候・気温に加え、**「🌦️ 詳細気象（降水量・風向・風速）」** を開いて記録できます（防除選択時は自動で開きます）。
4. **使用資材・収穫実績を入力（STEP 3）**：
   - **🧪 施肥**：総袋数を入れるだけで 10aあたり N-P-K 成分量を自動計算。
   - **🛡️ 防除**：2剤混用（タンクミックス）対応。**有効成分別の使用回数上限・収穫前日数(PHI)** を自動チェックし、違反時は登録をブロックします。
   - **🌾 収穫**：正米袋数・**屑米(kg)**・水分・等級・食味値を記録し、10a反収（kg/俵）を自動按分します。

#### 📸 収穫入力（屑米・食味計/検査伝票 OCR読取）
- 収穫パネル内の **「📸 食味計・伝票を写真読取」** を押して、食味計の画面やJA検査伝票の写真を撮ると、**食味値・水分・タンパク・整粒歩合・アミロース・脂肪酸度・等級・荷受袋数** を自動で読み取ってフォームへ入力できます（Gemini Vision APIキーはタブ5で設定可能。ローカル正規表現解析のみでも動作します）。

5. **「✅ 一括登録」を押す**：タイムラインへの追加と同時に、資材在庫の引き落とし・機械アワーの加算・圃場累計NPKの更新が完了します。

### 間違えて登録したときの直し方（編集・取消）
- 右側タイムラインの **「✏️ 編集」** で入力欄に内容を戻して修正でき、**「🗑️ 取消」** を押すと減った在庫や増えた機械アワー・累計NPKも自動で元に戻ります（自動ロールバック）。

## 5. 【地図・写真GPS】航空写真で囲む・写真から田んぼを自動判別する

### 方法A：登録済みの田んぼを航空写真でタップして選ぶ
- STEP 1 の **「🗺️ 航空写真マップで選択」** を開き、田んぼの枠（ポリゴン）またはピンをタップして選択／解除します。**「🚗 選択圃場をGoogleマップ経路案内」** で現地までのナビも開けます。

### 方法B：航空写真で田んぼを囲んで、面積を自動測量＆新規登録する（おすすめ！）
1. マップ右上の **「✏️ 地図上で田んぼを囲んで新規追加」** を押します。
2. 航空写真を拡大し、**田んぼの角（3箇所以上）を順番にクリック** します。
3. 赤い枠で囲まれ、**面積（約 ○○ a / ○○○ ㎡）がリアルタイム自動計算** されます。
4. **「✅ この範囲で圃場を登録」** を押し、圃場名と品種を入れて保存すれば完了です！

### 方法C：ドローン・スマホの写真から位置情報（EXIF GPS）で田んぼを自動判別する
1. タブ1の **「📷 写真GPS判別」**（またはタブ2の **「📷 写真GPS取込」**）を押します。
2. ドローンやスマホで現地撮影したJPEG写真（複数選択OK）を選びます。
3. ブラウザ内で外部送信なしに撮影地点の緯度・経度を読み取り、**どの登録圃場の敷地内で撮ったか（敷地外なら最寄り圃場と距離）** を自動判定します。
4. 判定結果から **「✅ 判別した圃場を作業対象にセット」**、**「🗺️ GISマップに撮影ピンを表示」**、または未登録地点から **「＋ この位置で新圃場を作成」** がワンクリックで行えます。

## 8. 【提出・AI分析】タブ4でJA帳票・採算試算・AI最適施肥分析をする

### 📄 6種類の帳票・AI分析モード切替
1. **📄 1. JA提出用「生産履歴記帳簿（施肥・防除）」**
   - 品種・団地・個別圃場で絞り込み、10aあたりN-P-K成分累計（面積加重平均）や農薬登録番号・有効成分別回数・PHI判定をJA様式で自動集計します。
2. **📋 2. 行政・法人用「作業日報・面積按分表」**
   - 作業者・機械・時間・天候・観察メモを時系列一覧で出力します。
3. **📊 3. 経営・GAP用「圃場別 反収×NPK×労働時間 採算総括表」**
   - 肥料費・農薬費・労務費・機械費と正米＋屑米売上から、**10aあたり粗利益と採算ランク（S / A / B / C）** を自動算出します（想定米価・屑米単価・時給シミュレーション対応）。
4. **📈 4. AI施肥分析「チッソ(N)施肥量 × 反収 二次曲線回帰」**
   - 最小二乗法（$y = ax^2 + bx + c$）で各圃場のチッソ施肥量と反収の関係をグラフ化し、**最も反収が高くなる最適チッソ量（ピーク値）** と決定係数 $R^2$ を自動算出します。
   - 各田んぼを **「🔴 過剰施肥（倒伏・食味低下リスク）」「🟢 適正範囲」「🔵 施肥不足（増収余地）」** に診断し、次作の増減肥アドバイスを表示します（実績3筆未満でも「📊 サンプル7筆で回帰曲線を試算」ボタンで体験できます）。
5. **🎯 5. AI経営分析「全圃場 4象限ポートフォリオ」**
   - 横軸に **10aあたり作業時間**、縦軸に **10aあたり粗利益**、円の大きさに **圃場面積** をとったバブルチャートを描画し、中央値（または平均値）を基準に全圃場を **🌟優良主力田／🔧改善余地田／💦労力過多田／⚠️要見直し田** の4グループへ自動分類します。
   - 実データ表示時はバブルをクリックすると該当圃場のGISカルテへ直接移動でき、グループ別の経営改善アクションも提示されます。
6. **📉 6. AI労務分析「時系列・労務＆コスト パレート(ABC)分析」**
   - 月別・旬別（上旬/中旬/下旬）の稼働推移グラフから **最大繁忙ピーク** を可視化します。
   - 作業分類ごとの労働時間・コストを降順集計したパレート図（棒＋累積構成比折れ線）で、全体の80%を占める **Aランク・ボトルネック作業**（例：畦畔草刈り等）を自動特定し、省力化スライダー（10〜30%減）で年間コスト削減額と創出時間をリアルタイム試算できます。

### 🖨️ A4印刷・PDF保存・CSV出力
- **「🖨️ A4フォーマットで一発印刷 / PDF保存」** で不要なボタンを隠してA4用紙へきれいに印刷・PDF保存できます。Excel加工用の **「📥 Excel/CSV出力」** にも対応しています。

## 10. よくある質問（FAQ）・困ったときは

### Q1. 音声入力が反応しません／圏外でも使えますか？
- **A.** Web Speech API は Chrome / Edge / Safari（iPhone）に対応しており、オンライン時に動作します。マイク許可のポップアップが出たら「許可」を押してください。圏外や非対応ブラウザでは、音声モーダル内のテキスト入力欄に「本場1号から3号まで草刈り2時間」と入力して「🔍 解析して反映」を押せば同じように自動セットされます。

### Q2. 航空写真や気象データが表示されません。
- **A.** オフライン（圏外）状態または「📡 圏外テスト切替」がオンの場合は、通信を使わないオフライン用SVGマップおよびキャッシュ/推定気象データに自動切替されます。オンライン復帰後に「🔄 更新」を押すと最新データが取得されます。

### Q3. ブラウザを閉じても数年分のデータは消えませんか？
- **A.** 消えません。大容量の `IndexedDB` に自動保存されるため、数年分の日誌や詳細なポリゴン座標も安全に保持されます。ただしブラウザの「閲覧履歴・サイトデータの全削除」を行うと消える場合があるため、定期的に **[タブ5] ＞「📥 JSONバックアップ保存」** を行ってください。
