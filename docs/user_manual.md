## 1. アプリの開き方・基本の仕組み（オフライン自動保存）

### 💻 パソコン・スマホでの開き方
- フォルダ内の **`index.html`** をダブルクリックすると、普段お使いのブラウザ（Google Chrome / Edge / Safari など）ですぐに開きます。
- インターネット環境がある場所では **Googleマップの航空写真（衛星画像）** が表示され、山間部などの電波圏外では自動的に **オフライン対応マップ** に切り替わります。

### 💾 データの自動保存について
- 入力した日誌、追加した田んぼ・農機具・肥料・農薬のデータは、すべてお使いのスマホ・パソコン本体（ブラウザの `localStorage`）に**自動で即座に保存**されます。
- 電波が届かない山間部の田んぼで入力しても、データが消えることはありません。
- 機種変更やパソコンの買い替え時に備えて、定期的に **[タブ5] ＞「📥 JSONバックアップ保存」** でファイルに保存しておくことをおすすめします。

## 2. 画面の構成（5つのメインタブ）

画面上部の5つのボタンで機能を切り替えます。

| タブ番号・名称 | 主な役割・できること |
| :--- | :--- |
| **📱 1. 現場一括入力** | 毎日の作業日誌（施肥・防除・草刈・耕起・収穫・観察日誌）の入力、Googleマップでの田んぼ選択・新規作図、過去日誌の検索・修正 |
| **🗺️ 2. GIS進捗・カルテ** | 作業別の進捗色分けマップ、田んぼごとの詳細カルテ、水稲の出穂後積算温度（1,000℃刈取適期予測）、獣害・水漏れ等の見回りアラート |
| **🚜 3. 機械・資材在庫** | トラクター・コンバイン等の新規追加・アワーメーター点検管理、肥料・農薬の新規銘柄追加・入庫補充・在庫確認 |

## 3. 【タブ1】現場での作業日誌・営農日誌（天候・メモ）のつけ方

複数の田んぼで同じ作業をした場合でも、**1回の入力で面積比に応じて自動按分**されます。

### 手順①：作業日・作業者を確認する
- 画面左上の日付欄（**「📅 今日」** ボタンで本日にセット可能）と作業者名を確認します。
- **「⚡ ワンタップ履歴呼び出し」**（基肥散布・ドローン防除・畦畔草刈り）を押すと、よく使う設定を一発でセットできます。

### 手順②：作業した田んぼ（圃場）を選ぶ（STEP 1）
複数の選び方があります。
1. **タイルをタップして選ぶ**：田んぼのカードをクリックすると緑色の選択状態（`✓`）になります。
2. **団地ごと一括で選ぶ**：「⛰️ 上山田団地を一括選択」「🌊 川向団地を一括選択」でまとめて選択できます。
3. **📍 実GPS現在地周辺を選択**：今いる場所から近い田んぼを自動で選びます。
4. **🗺️ Googleマップで選択**：航空写真を見ながら田んぼをタップして選べます（詳しくは[第4章](#4-googleマップ連携航空写真での圃場選択田んぼを囲んで新規作図経路案内)）。

### 手順③：作業分類と使用資材・機械を入力する（STEP 2・STEP 3）
6つの作業分類からタブを選びます。

- **🌱 施肥**：肥料銘柄と「全体で使った総袋数（または総kg）」を入力します。選んだ田んぼの面積比で10aあたりチッソ(N)・リン酸(P)・カリ(K)成分量が自動計算されます。
- **🚁 防除（農薬）**：第1農薬（必要に応じて第2農薬も混用可能）、希釈倍率、総散布量を入力します。**有効成分ごとの総使用回数上限**や**収穫前日数（PHI）**を自動チェックし、基準超過時は赤い警告でお知らせします。
- **🌿 草刈り・畦畔** / **🚜 耕起・代かき**：作業内容と使用した機械を選びます。
- **🌾 収穫・刈取**：収穫した総重量（kg または 30kg袋数）と品質等級を入力すると、各田んぼの **10aあたり反収（kg・俵）** が自動計算されます。
- **📔 観察・日誌のみ**：肥料や農薬を使わない日々の見回り記録（水回り確認、生育ステージ観察など）を残せます。

### 手順④：営農日誌（天候・気温・観察メモ）を入力する
- **天候**（☀️晴・⛅曇・🌧️雨など）と **気温(℃)** を入力できます。
- **生育観察・作業メモ・引き継ぎ事項** には自由な文章を入力できます。下の「💧 水回り・落水確認」「🐗 畦畔・獣害点検」などのクイックタグを押すと、ワンタップで定型文を追記できます。

### 手順⑤：「✅ この内容で一括登録」ボタンを押す
- 画面下の緑色の大きなボタンを押すと登録完了です。
- 右側の **「📔 営農日誌・作業タイムライン」** に即座に追加され、以下がすべて自動で連動します。
  - 各田んぼの累積チッソ・リン酸・カリ成分量、農薬回数、進捗ステータスの更新
  - 肥料・農薬の現在庫からの自動引き落とし
  - 使用した農機具のアワーメーター（稼働時間）の自動加算

> 💡 **間違えて登録したときは？**  
> 右側のタイムラインにある各履歴カードの **「✏️ 編集」** を押すと入力フォームに内容が呼び出されて修正（上書き保存）できます。**「🗑️ 取消」** を押すと履歴が削除され、減った在庫や機械アワーも自動で元に戻ります。

## 4. 【Googleマップ連携】航空写真での圃場選択・田んぼを囲んで新規作図・経路案内

Googleマップの衛星写真（ハイブリッド航空写真）を使って、直感的に田んぼを選んだり、新しい田んぼの形と面積を登録できます。

### 方法A：登録済みの田んぼをGoogleマップ上でタップして選ぶ
1. **[📱 1. 現場一括入力]** タブの STEP 1 にある **「🗺️ Googleマップで選択」** ボタンを押します（または **[🗺️ 2. GIS進捗・カルテ]** タブで **「🛰️ Googleマップ(航空写真)」** に切り替えます）。
2. 航空写真の上に登録済みの田んぼの枠（ポリゴン）とピンが表示されます。
3. **田んぼの枠またはピンをタップ** すると、選択（緑色 `✓`）／解除が切り替わります。

### 方法B：地図上で田んぼの四隅をクリックして囲み、面積を自動測量して新規登録する（おすすめ！）
まだ登録していない新しい田んぼを、航空写真を見ながらその場で追加できます。
1. Googleマップ選択パネルの右上にある **「✏️ 地図上で田んぼを囲んで新規追加」** ボタンを押します。
2. 航空写真を拡大し、**追加したい田んぼの角（四隅など）を順番に3箇所以上クリック** します。
3. クリックするたびに赤い点線で田んぼが囲まれ、画面上に **測地線面積（約 ○○ a / ○○○ ㎡）がリアルタイムで自動計算** されます。
   - 点を打ち直したいときは **「🗑️ 頂点をクリア」** を押します。
4. 囲み終わったら **「✅ この範囲で圃場を登録」** ボタンを押します。
5. 自動で **[🔄 5. 他社データ移行・設定]** の新規圃場登録フォームが開き、**緯度・経度・面積(a)・ポリゴン形状がすべて自動入力された状態** になります。
6. あとは **「圃場名（例：山田3号田）」** や **「品種」** を入れて **「＋ 圃場マスタへ追加保存」** を押すだけで、新しい田んぼが登録され選択状態になります。

### 方法C：選んだ田んぼへGoogleマップで経路案内（ナビ）する
- 飛び地や新しく借りた田んぼへ行くときは、STEP 1 の **「🚗 選択圃場をGoogleマップ経路案内」** ボタン（または各田んぼカルテの **「🗺️ Googleマップで開く」**）を押すと、Googleマップのルート検索・ナビ画面が別タブで開きます。

## 5. 【タブ2】GIS進捗マップ・積算温度（刈取予測）・見回り被害アラート

**[🗺️ 2. GIS進捗・カルテ]** タブでは、地域全体の作業の進み具合や生育・被害状況を一目で把握できます。

### 🗺️ 作業別の進捗色分けマップ
- 上部のボタン（**🌱 基肥・施肥進捗** ／ **🚁 防除進捗** ／ **🌿 畦畔草刈り** ／ **🌾 収穫・反収**）を切り替えると、各田んぼが「完了（緑）」「作業中（青）」「未着手（灰）」「要注意（赤）」で色分け表示されます。
- **「📐 進捗ボード」** と **「🛰️ Googleマップ(航空写真)」** をワンタップで切り替えられます。

### 🌡️ 水稲「出穂後積算温度（1,000℃）」＆刈取適期予測
- 右側の「圃場個別カルテ」で田んぼを選び、**「🌾 出穂日」** と **「🌡️ 日平均気温(℃)」** を設定すると、出穂後からの積算温度と目標1,000℃に対する進捗バー、および **刈取適期予測日（あと何日か）** が自動表示されます。

### 📸 現地見回りメモ＆被害アラート（獣害・水漏れ・雑草）
- 田んぼを見回って異常を見つけたときは、右側のカルテ下部にある **「⚠️ 被害・見回りメモ」** に内容（例：「北側畦畔にイノシシ掘り返し跡あり」）を入力し、区分（🐗獣害・💧水漏れ・🌿雑草・🐛病害虫）を選んで **「＋ アラート追加」** を押します。
- 未解決のアラートがある田んぼには、マップやタイル上に赤い **`⚠️`** マークが表示され、処置が終わったら **「✓ 解決済」** ボタンで消込できます。

## 6. 【タブ3】機械（農機具）・肥料・農薬の追加・削除と在庫・点検管理

**[🚜 3. 機械・資材在庫]** タブ（または **[🔄 5. 他社データ移行・設定]** タブ）から、お使いの農機具や資材を自由に追加・管理できます。

### 🚜 農機具（機材）の追加・オイル交換点検リセット
1. **新規機材の追加**：「**＋ 新規機材を追加**」ボタンを押し、機材名（例：`クボタ コンバイン ER470`）、分類、現在アワー(h)、点検間隔(hごと)、稼働単価(円/h)を入力して保存します。
2. **自動加算とアラート**：日誌でその機械を使って作業登録すると稼働時間が自動加算され、点検間隔（50時間ごと等）に近づくと **「オイル交換時期超過」** アラートが表示されます。
3. **点検・整備記録**：「🔧 オイル交換・点検済として記録」ボタンを押すと、点検完了としてカウントがリセットされます。不要になった機材は **「🗑️ 削除」** で削除できます。

### 🧪 肥料・🛡️ 農薬の新規追加と入庫補充
1. **肥料の追加**：「**＋ 肥料を追加**」ボタンから、肥料名・N/P/K成分(%)・1袋重量(kg)・初期在庫・単価を入力して登録します。
2. **農薬の追加**：「**＋ 農薬を追加**」ボタンから、農薬名・登録番号・**有効成分名**・使用上限回数・収穫前日数(PHI)・初期在庫・単価を入力して登録します。
3. **在庫の入庫補充**：JAや資材店から追加購入したときは、各資材カードの **「＋10袋 入庫補充」** などのボタンを押すと在庫数が加算されます。

## 7. 【タブ4】JA提出用「生産履歴記帳簿」・A4印刷・10aあたり採算ランク試算

**[🖨️ 4. JA・行政 A4帳票]** タブでは、日々の入力データから提出用書類や経営分析表を自動作成します。

### 📄 3種類の帳票モード切替
1. **JA提出用「生産履歴記帳簿」**
   - 品種（コシヒカリ・つきあかり等）や団地・個別圃場で絞り込みが可能。
   - **施肥履歴（10aあたりN-P-K成分累計）** と **防除履歴（農薬登録番号・有効成分別の総使用回数・収穫前日数判定・最終散布日からの経過日数）** がJA提出フォーマットで自動集計されます。
2. **作業日報・労務機械稼働一覧**
   - 誰が・いつ・どの田んぼで・どの機械を何時間動かしたか、当日の天候・観察メモを含めた一覧表を出力します。
3. **💴 圃場別「10aあたり原価・粗利・採算性」試算表**
   - 各田んぼに投入した **肥料費＋農薬費＋労務費＋機械稼働費** と、収穫した **反収×米価（売上）** から、**10aあたりの粗利益と採算ランク（S / A / B / C）** を自動算出します。
   - 画面上の「想定米価（円/60kg俵）」や「労務時給（円/h）」を変えると、リアルタイムで全圃場の採算シミュレーションが更新されます。

### 🖨️ A4印刷・PDF保存・CSV出力
- **「🖨️ A4横サイズで印刷 / PDF保存」** ボタンを押すと、ボタンやメニューが自動的に隠れ、A4用紙にきれいに収まるレイアウトで印刷（またはPDF保存）できます。
- Excelで加工したい場合は **「📥 帳票CSV出力」** を押すと、文字化けしないBOM付きCSVファイルがダウンロードされます。

## 8. 【タブ5】他社アプリからのデータ移行・Googleスプレッドシート連携・バックアップ復元

**[🔄 5. 他社データ移行・設定]** タブでは、外部データとの連携やバックアップを行います。

### 🔄 他社営農ソフト・行政データの1クリック取り込み
- **アグリノート (AgriNote)** のほ場台帳CSV（面積 `㎡` を `a` に自動換算）
- **クボタ KSAS** の作業日誌CSV（面積 `ha` を `a` に自動換算）
- **農林水産省 eMAFF農地ナビ / Z-GIS** の筆ポリゴン（GeoJSONファイル）
- サンプル読込ボタンまたはファイル選択で読み込み、プレビュー確認後に **「✅ 変換データをマスタ・履歴へ一括統合」** を押すだけで取り込めます。

### ☁️ Googleスプレッドシート（GAS）連携
- 同梱の `gas/Code.gs` をGoogleスプレッドシートに設定して発行したウェブアプリURLを入力すると、**「☁️ スプレッドシート同期」** ボタン1つでスマホ内の日誌データをGoogleスプレッドシートへ一括送信できます（詳しい構築手順は `docs/pwa_and_gas_setup_guide.md` をご覧ください）。

### 💾 JSONバックアップ保存・1クリック復元・初期リセット
- **「📥 JSONバックアップ保存」**：現在の全データを1つの `.json` ファイルとしてパソコンやスマホに保存します。
- **「📤 JSONバックアップから復元」**：保存しておいた `.json` ファイルを選ぶだけで、すべての田んぼ・在庫・日誌データを1クリックで元通りに復元します。
- **「🔄 初期サンプルにリセット」**：練習でいろいろ入力した後、最初のサンプル状態に戻したいときに使います。

## 9. よくある質問（FAQ）・困ったときは

### Q1. Googleマップの航空写真が表示されず、図形（SVG）のマップになります。
- **A.** パソコンやスマホがインターネットに繋がっているかご確認ください。オフライン（圏外）状態や「📡 圏外テスト切替」がオンになっている場合は、通信を使わないオフライン用マップが表示されます。

### Q2. 新しい田んぼの緯度・経度がわかりません。
- **A.** 緯度・経度を手入力する必要はありません！ **[📱 1. 現場一括入力]** タブの **「🗺️ Googleマップで選択」＞「✏️ 地図上で田んぼを囲んで新規追加」** を使えば、航空写真の上で田んぼの角をクリックするだけで位置・形状・面積(a)がすべて自動入力されます。また、Googleマップの共有URLを貼り付けて座標を自動抽出することもできます。

### Q3. 複数の田んぼにまとめて肥料をまいたとき、1枚ずつの量はどう計算されますか？
- **A.** たとえば 30a と 20a の田んぼ（合計50a）を選んで「合計10袋（200kg）」と入力すると、面積比（3:2）に応じて自動的に **30aの田んぼに120kg、20aの田んぼに80kg（どちらも10aあたり40kg）** として配分・記録されます。

### Q4. ブラウザを閉じてもデータは消えませんか？
- **A.** 消えません。ブラウザの `localStorage` に自動保存されているため、次回開いたときも続きから使えます。ただし「ブラウザの閲覧履歴・キャッシュの全削除」を行うと消える場合があるため、大切なデータは定期的に **[タブ5] ＞「📥 JSONバックアップ保存」** でファイルに保存してください。
