## 1. プロトタイプ検証ツールの比較選定（AppSheet vs Glide vs カスタムPWA）

最速で現場テストを実施するにあたり、本システムの必須要件（**①完全オフライン対応、②地図からの複数圃場選択、③1作業×複数圃場の自動按分、④A4定型帳票PDF/Excel出力**）に対する適合性を比較しました。

| 評価軸 | **Google AppSheet**（推奨：最速試作） | **Glide** | **カスタムWebアプリ (PWA)**（本開発向け） |
| :--- | :--- | :--- | :--- |
| **① 完全オフライン対応（山間部）** | **◎ 標準対応**<br>端末内にキャッシュし、電波復帰時に自動バックグラウンド同期が可能。 | **△ 制限あり**<br>基本的にはオンライン前提。電波圏外での新規登録・リレーション処理に弱い。 | **◎ 完全制御可能**<br>IndexedDB + Service Workerにより航空写真タイル含め完全オフライン化可能。 |
| **② GISマップ・複数圃場選択** | **○ 対応**<br>KMLポリゴン表示やXYマップピン表示に対応。`EnumList`で複数圃場選択が可能。 | **△ ピン表示中心**<br>水田の区画（ポリゴン）色分けやヒートマップ表現が難しい。 | **◎ 自由自在**<br>Leaflet / MapLibre等で航空写真上の区画タップ複数選択・ヒートマップを直感操作。 |
| **③ 1作業×複数圃場の面積按分** | **◎ Bot / Actionループで実装可**<br>親フォーム保存時に選択圃場分の明細行を自動生成・計算可能。 | **○ Make/Zapier連携またはAction**<br>外部連携を使うとオフライン時に動作しない課題あり。 | **◎ 即時計算**<br>入力中にリアルタイムで按分プレビューを表示可能（モックアップ参照）。 |
| **④ JA・行政用 A4完成帳票出力** | **◎ 標準BotでPDF/Excel生成**<br>Googleドキュメント/スプレッドシートのA4テンプレートへ差し込み印刷が可能。 | **△ 外部連携が必要**<br>A4の細かい罫線帳票（JA様式）を作るにはDocsAutomator等の別課金が必要。 | **◎ 完全再現可能**<br>既存Excelテンプレートへの直接流し込み（SheetJS等）やA4印刷CSSで一発出力。 |
| **総合判定** | **🏆 現場プロトタイプ検証の第1候補** | UIは綺麗だが山間部オフラインとJA帳票に難あり | **🏆 プロトタイプ検証後の製品化（本開発）候補** |

> [!IMPORTANT]
> **結論：現場テスト（プロトタイプ）は「AppSheet ＋ Googleスプレッドシート」が最適**
> 中山間地での**「完全オフライン入力」**と、JA・行政向けの**「A4罫線付き定型帳票（PDF/Excel）の自動生成」**が追加開発費なしで標準機能として揃っているため、ノーコード検証は **AppSheet** を強く推奨します。

### 2.1 AppSheetでの主要カラム計算式（App Formula）設定

`04_T_WORK_LOGS`（作業日誌テーブル）に以下の計算式を設定することで、作業者が「圃場（複数）」と「袋数」を選ぶだけで全項目が自動計算されます。

1. **選択圃場の合計面積 `total_area_a` の自動計算**:
   ```excel
   SUM(SELECT(M_FIELDS[area_a], IN([field_id], [_THISROW].[selected_field_ids])))
   ```
2. **肥料の総重量 `total_weight_kg` と 10aあたりチッソ量 `calc_n_per10a_kg` の自動計算**:
   ```excel
   // 総重量 (kg)
   [input_qty_bags_or_bottles] * [material_id].[unit_size]

   // 10aあたりチッソ成分量 (kg/10a)
   ([total_weight_kg] / ([total_area_a] / 10.0)) * ([material_id].[n_ratio_pct] / 100.0)
   ```
3. **防除時の必要総水量 `water_volume_l` と 必要薬量（mL）の逆算**:
   ```excel
   // 必要総水量 (L) ※10aあたり100L散布の場合
   ([total_area_a] / 10.0) * 100.0

   // 必要農薬原液量 (mL)
   ([water_volume_l] * 1000.0) / [dilution_rate]
   ```
4. **農薬安全基準（使用回数・収穫前日数）の入力時バリデーション（`Valid_If`）**:
   ```excel
   // 収穫予定日までの日数が農薬の収穫前日数制限(pre_harvest_days)以上あるかチェック
   MIN(SELECT(M_FIELDS[planned_harvest_date], IN([field_id], [_THISROW].[selected_field_ids]))) - [work_date]
   >= [material_id].[pre_harvest_days]
   ```

### 2.2 オフライン設定（山間部対応）の有効化手順
AppSheetエディタの **`Settings` > `Offline/Sync`** にて以下の3つをONにします：
- `Offline use`: **ON**（電波圏外でのアプリ起動・データ閲覧・フォーム入力を許可）
- `Delayed sync`: **ON**（圏外ではローカルキューに保存し、電波復帰時に一括送信）
- `Automatic updates`: **ON**（バックグラウンド同期）

## 3. JA・行政・GAP提出用 A4帳票テンプレート出力仕様

既存の「らくらく営農日誌」の強みであるA4完成帳票を継承し、現場の手作業清書を完全排除するため、以下の3種類のA4帳票レイアウトを標準搭載します（インタラクティブモックアップの「🖨️ 4. JA・行政 A4完成帳票」タブにて実際のプレビューと印刷・CSV出力を確認できます）。

### 様式1：JA提出用「生産履歴記帳簿（施肥台帳・防除履歴簿）」
- **用紙サイズ・向き**: A4横（一覧性重視）
- **ヘッダ印字項目**:
  - 年度、生産者コード・氏名、対象品種名（例：コシヒカリBL）、対象圃場グループ（または地番リスト）、合計作付面積(a)、種子消毒方法、田植日、収穫日
- **【上段】施肥台帳ブロック**:
  - `施用年月日` | `対象圃場名` | `面積(a)` | `肥料名称` | `成分比(N-P-K)` | `総使用量(袋/kg)` | `10aあたり施用量(kg)` | `10aあたり成分量(N / P / K kg)`
  - **最下行（自動合計行）**: 作期を通じた **10aあたり累計チッソ(N)・リン酸(P)・カリ(K) 合計値**（JAの特別栽培米・減化学肥料栽培の審査基準値と自動照合）
- **【下段】防除履歴簿ブロック**:
  - `散布年月日` | `対象圃場名` | `面積(a)` | `農薬名（農林水産省登録番号・有効成分）` | `対象病害虫・雑草` | `希釈倍率` | `10aあたり使用量(薬量・散布液量)` | `散布方法(ブーム/ドローン等)` | `延べ使用回数 / 上限回数` | `収穫前日数判定（適）`

### 様式2：行政・農業法人・経営管理用「作業日報 兼 圃場別面積按分実績表」
- **用紙サイズ・向き**: A4縦 または A4横
- **印字項目**:
  - `作業日` | `天候` | `作業者名` | `作業分類` | `対象圃場（一括表記＆個別按分内訳）` | `合計作業面積(a)` | `実作業時間(h)` | `10aあたり労働時間(h/10a)` | `使用機械名` | `使用資材摘要`
- **活用用途**:
  - 農業法人の労務管理、品目別・圃場別のコスト分析（10aあたり労働時間の算出）、中山間地域等直接支払交付金や環境保全型農業直接支払交付金の活動記録提出用。

### 様式3：GAP監査用「農機具点検・整備記録簿 兼 資材在庫受払台帳」
- **用紙サイズ・向き**: A4縦
- **印字項目**:
  - **機械パート**: `機械名・型式` | `累計稼働時間(h)` | `日常点検・オイル交換実施日` | `実施時アワーメーター` | `整備内容・交換部品` | `点検実施者サイン`
  - **資材在庫パート**: `資材名（肥料・農薬）` | `購入入庫日・数量` | `使用出庫日・使用圃場・数量（日誌より自動転記）` | `現在庫残高` | `保管庫点検確認`
