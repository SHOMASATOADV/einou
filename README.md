# 🌾 次世代版「らくらく営農日誌 Next」プロジェクト

「らくらく営農日誌」をベースに、**「作業日報（労務・機械）」と「圃場管理記録（施肥・防除・収穫）」の1アクション完全統合**、**中山間地・飛び地での現場ファーストUI（完全オフライン・GPS連動・片手操作）**、および**JA・行政・GAP提出用A4完成帳票への一発出力**を実現する統合営農管理システムプロジェクトです。

## ✨ 主な機能ハイライト

- **🌾 1アクション複数圃場・面積按分記録**: 施肥・防除（2剤タンクミックス混用＆有効成分別回数・PHI安全基準判定）・草刈り・耕起・収穫（反収自動計算）を1画面で登録。
- **📔 営農日誌タイムライン（天候・気温・観察メモ・検索）**: 当日の天候・気温・生育観察メモ・引き継ぎ事項を記録し、キーワード・作業分類で検索＆その場で編集・取消が可能。
- **🗺️ Googleマップ（航空写真）連動の圃場選択＆位置取得**: Google衛星写真上で田んぼをタップして対象圃場を選択、複数選択圃場のGoogleマップ経路案内、新規圃場登録時のGoogleマップURL座標抽出＆地図クリック位置指定に対応。
- **🚜 機材（農機具）・🧪 肥料・🛡️ 農薬・🌾 圃場のマスタ追加＆削除**: トラクター・コンバイン・ドローン等の新規機材や、肥料・農薬（有効成分・PHI連動）をタブ3・タブ5からいつでも追加・削除可能。
- **🌡️ 水稲「出穂後積算温度（1,000℃）」＆刈取適期予測**: GISヒートマップおよび圃場カルテで出穂日からの積算温度と刈取適期予測日を可視化。
- **📸 現地見回りメモ＆被害アラート（獣害・水漏れ・雑草）**: 圃場カルテから1タップでピン留めし、GISマップや圃場タイルに `⚠️` バッジを表示。
- **💴 圃場別「10aあたり原価・粗利・採算性」自動試算**: 肥料費・農薬費・労務費・機械費・反収から圃場ごとの粗利益と採算ランク（S/A/B/C）を自動算出（米価・時給シミュレーション対応）。
- **💾 JSONフルバックアップ＆1クリック復元**: 端末内の全マスタ・作業履歴・在庫データをJSONファイルで保存・復元可能。

## 🚀 クイックスタート

1. **スマホ・ブラウザでPWAプロトタイプを動かす**
   - `index.html` をブラウザで開くと、現場一括入力・GIS進捗ヒートマップ・機械アワー・JA提出A4帳票出力・他社アプリデータ移行の全機能がその場で動作し、データは端末内（`localStorage`）に自動保存されます。
2. **Googleスプレッドシート ＋ GAS で自動按分＆A4帳票環境を作る**
   - 空のGoogleスプレッドシートを開き、「拡張機能 ＞ Apps Script」に `gas/Code.gs` を貼り付けてメニュー『🌾 らくらく営農日誌 ＞ ① 初期シート＆A4帳票テンプレートを一括作成』を実行してください（詳細は `docs/pwa_and_gas_setup_guide.md` 参照）。
3. **既存Excelで動かす**
   - ExcelのVBE（`Alt + F11`）に `excel_vba/RakurakuEinouMacro.bas` をインポートすると、CSV取込・面積按分・A4 PDF出力がワンクリックで実行できます。
